    Uploading to TradeZella

    1. Add Trades → Upload file, choose the Generic Template importer.
    2. Time zone: pick US/Eastern — it must match the setting above.
    3. Date Format: MM/DD/YY.
    4. Upload under Execution-based format (one row per fill). The columns already match the template, so mapping should be automatic.
    WealthCharts: mov_time → Date/Time, sign of exec_qty → Buy/Sell, |exec_qty| → Quantity, price_done → Price. points and profit are intentionally dropped — TradeZella recalculates P&L from the executions.
    Tradesea: Time → Date/Time, Side → Buy/Sell, Qty → Quantity, Avg Price → Price, Commission → Commission. Only rows with Status Filled are used. CME:MES becomes MESZ6 — TradeZella rejects a bare root for futures, so the front-month code is appended (or the one you set above).
